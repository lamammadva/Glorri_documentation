# Notification System

**Bildirişlər** bölməsində hesabınızla və işə qəbul prosesləri ilə bağlı sistem bildirişlərini görə bilərsiniz.

Buradan:

* Yeni bildirişləri izləyə;
* Namizəd, vakansiya və tapşırıq üzrə bildirişləri axtara;
* Bildirişləri yenilik və tarixə görə sıralaya;
* Bütün bildirişləri oxunmuş kimi işarələyə;
* Bildirişdən birbaşa müvafiq vakansiya və ya namizəd profilinə keçə bilərsiniz.
