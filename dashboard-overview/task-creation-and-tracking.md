# Task Creation and Tracking

**Tapşırıqlar** bölməsində komanda üzvlərinə yeni tapşırıqlar təyin edə və onların icra vəziyyətini izləyə bilərsiniz.

Buradan:

* Yeni tapşırıq yarada;
* Bütün tapşırıqlara baxa;
* Yalnız sizə təyin edilmiş tapşırıqları görə;
* Aktiv, tamamlanmış və vaxtı keçmiş tapşırıqları izləyə;
* Tapşırıqları təqvim üzərindən tarixə görə görə bilərsiniz.

> Tapşırıqların yaradılması və idarə edilməsi haqqında ətraflı məlumat üçün **Tapşırıqlar** bölməsinə keçin.
