# Calendar Features

**Təqvim** bölməsi vakansiyalar, müsahibələr və tapşırıqlarla bağlı planlaşdırılmış fəaliyyətləri vahid təqvim üzərində izləməyə imkan verir.

Buradan:

* Bütün vakansiyalar üzrə tədbirləri;
* Müəyyən vakansiyaya aid müsahibə və tapşırıqları;
* Ay, həftə və gün görünüşlərini

seçərək planlaşdırılmış fəaliyyətləri izləyə bilərsiniz.
