# Pipeline elementlərinin sıralanmas

**Pipeline elementlərini artan və ya azalan sıra ilə göstərin.**

**Pipeline items sorting** parametri pipeline daxilində elementlərin hansı ardıcıllıqla göstəriləcəyini müəyyən edir.

* **Ascending (ASC)** — elementləri artan sıra ilə göstərir.
* **Descending (DESC)** — elementləri azalan sıra ilə göstərir.

Seçdiyiniz sıralama qaydası pipeline görünüşünə tətbiq olunur.
