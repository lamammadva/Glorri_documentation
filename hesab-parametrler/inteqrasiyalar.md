# İnteqrasiyalar

**İşə qəbul proseslərinizi üçüncü tərəf xidmətləri ilə inteqrasiya edərək daha səmərəli idarə edin.**

İnteqrasiyalar bölməsi vasitəsilə Glorri-ni dəstəklənən xidmətlərlə əlaqələndirə bilərsiniz. İnteqrasiya edildikdən sonra həmin xidmətlərdən birbaşa Glorri üzərindən istifadə edə və işə qəbul proseslərinizi daha rahat idarə edə bilərsiniz.

### Mövcud inteqrasiyalar

#### Zoom

Zoom hesabınızı Glorri ilə əlaqələndirərək namizədlər üçün onlayn müsahibələr planlaşdıra və idarə edə bilərsiniz.

**→ Zoom-u qoş**

***

#### Microsoft Teams

Microsoft Teams hesabınızı qoşaraq müsahibələri Teams üzərindən təşkil edə və görüş bağlantılarını birbaşa Glorri-də yarada bilərsiniz.

**→ Microsoft Teams-i qoş**

***

#### Microsoft Outlook

Microsoft Outlook hesabınızı inteqrasiya edərək təqviminizi sinxronlaşdıra, müsahibələri planlaşdıra və dəvətləri daha rahat idarə edə bilərsiniz.

**→ Microsoft Outlook-u qoş**

### İnteqrasiyanı necə qoşmaq olar?

1. **Hesab Parametrləri → İnteqrasiyalar** bölməsinə daxil olun.
2. Qoşmaq istədiyiniz xidməti seçin.
3. **Qoş** düyməsinə klikləyin.
4. Hesabınıza daxil olun və tələb olunan icazələri təsdiqləyin.
5. İnteqrasiya tamamlandıqdan sonra xidmət Glorri hesabınızda aktiv olacaq.

**Qeyd:** İnteqrasiya zamanı və ya istifadə prosesində hər hansı problem yaranarsa, əvvəlcə mövcud inteqrasiyanın əlaqəsini kəsin (**Disconnect**) və daha sonra yenidən qoşun (**Connect**). Problem davam edərsə, Glorri dəstək komandası ilə əlaqə saxlayın.
