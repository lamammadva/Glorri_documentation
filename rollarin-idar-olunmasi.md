# Rolların idarə olunması

Yeni rol yaratmaq üçün **Create Role** düyməsinə klikləyin.

Rol yaradarkən aşağıdakı məlumatları daxil edin:

* **Role Name** – Rolun adı _(məcburidir)_
* **Description** – Rolun təsviri _(istəyə bağlıdır)_
* **Permissions** – Rol üçün veriləcək icazələr

Glorri-də bütün istifadəçilər platformanın bütün bölmələrinə giriş əldə etmir.

Gördüyünüz bölmələr və edə bildiyiniz əməliyyatlar sizə təyin edilmiş **rol və icazələrdən** asılıdır.

Məsələn:

* vakansiyaları görə bilərsiniz;
* namizədlərə baxa bilərsiniz;
* namizədləri mərhələlər arasında keçirə bilərsiniz;
* müsahibə təşkil edə bilərsiniz;
* tapşırıq yarada bilərsiniz;

lakin bunların hər biri sizin rolunuza uyğun olaraq ayrıca məhdudlaşdırıla bilər.

Əgər hər hansı əməliyyatı həyata keçirə bilmirsinizsə, bu, həmin əməliyyat üçün lazımi icazənizin olmadığını göstərə bilər.

Lazımi icazələri seçdikdən sonra **Create** düyməsinə klikləyin. Yaradılmış rol Roles siyahısında görünəcək.

Digər rollar üçün isə aşağıdakı əməliyyatlar mümkündür:

* **Edit** – Rolun adını və icazələrini dəyişmək
* **Duplicate** – Mövcud rolun eyni nüsxəsini yaratmaq
* **Delete** – Rolu silmək

> **Qeyd:** Default **Admin** rolu redaktə edilə və silinə bilməz.

**Admin** şirkət hesabında geniş səlahiyyətlərə malik istifadəçidir. Adminlər sistemin bütün əsas bölmələrinə giriş əldə edə və müvafiq idarəetmə əməliyyatlarını həyata keçirə bilərlər. Admin rolunun icazələri fərdiləşdirilə və dəyişdirilə bilməz.

**Super Admin** isə şirkətin Glorri-də qeydiyyatdan keçmiş ilk istifadəçisidir və avtomatik olaraq Super Admin roluna təyin olunur. Super Admin şirkət hesabı üzərində ən yüksək səlahiyyətə malikdir.

Super Admin:

* şirkət hesabını idarə edə;
* admin və digər komanda üzvlərini idarə edə;
* rollar və icazələr üzərində dəyişikliklər edə;
* şirkət hesabını və sonradan təyin edilmiş adminləri silə bilər.

> **Qeyd:** Şirkət hesabını və sonradan təyin olunan adminləri silmək hüququ yalnız **Super Admin**-ə məxsusdur.
