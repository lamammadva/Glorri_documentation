# Yeni qovluq yaradılması

Namizəd Bazasına daxil olduqdan sonra namizədlərinizi daha rahat idarə etmək üçün yeni qovluq yarada bilərsiniz.

Bunun üçün:

1. **Yeni qovluq** düyməsini klikləyin.

<figure><img src="../.gitbook/assets/Paragraf metniniz.jpg" alt=""><figcaption></figcaption></figure>

1. Qovluğun adını daxil edin.
   * Məsələn: **Maliyyəçilər**
2. Qovluğun aid olduğu:
   * **Filialı (Ofisi)** seçin.
   * **Strukturu (Departament, şöbə və s.)** seçin.
3. Qovluğa giriş icazəsi olacaq istifadəçiləri (komanda üzvlərini) seçin. _(İstəyə bağlıdır.)_
4. **Əlavə et** düyməsini klikləyin.

Beləliklə, yeni qovluq yaradılmış olacaq.
