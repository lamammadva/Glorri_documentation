# API inteqrasiyası

**Nədir?**

Glorri-dəki vakansiya məlumatlarının şirkətin digər sistemləri və ya korporativ veb-saytı ilə API vasitəsilə inteqrasiya olunmasına imkan verir.

**Necə işləyir?**

API inteqrasiyası vasitəsilə şirkətin texniki sistemi Glorri-də mövcud olan vakansiya məlumatlarını əldə edib öz sistemində istifadə edə bilər.

Bu yanaşma xüsusilə şirkətin öz karyera portalı, HR sistemi və ya digər daxili platforması olduqda faydalıdır.

**Nə üçün istifadə olunur?**

API inteqrasiyası şirkətə:

* vakansiya məlumatlarını avtomatik əldə etmək;
* vakansiyaları öz platformasında göstərmək;
* sistemlər arasında məlumat mübadiləsi yaratmaq;
* əl ilə məlumat köçürülməsinin qarşısını almaq

imkanı verir.

**Texniki məlumat:**

`Koda bax` düyməsindən API inteqrasiyası üçün tələb olunan texniki məlumat və nümunə istifadə qaydaları əldə edilə bilər.

> **Qeyd:** API-dən istifadə etmək üçün texniki biliklər tələb oluna bilər. İnteqrasiya şirkətin developer/IT komandası tərəfindən həyata keçirilməlidir.
