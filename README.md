# Giriş

Əgər sizə birbaşa vakansiya yaratmaq icazəsi verilməyibsə, ehtiyacınız olan vakansiya üçün **Vakansiya sifarişi** yarada bilərsiniz.

Vakansiya sifarişi şirkət daxilində yeni əməkdaşa ehtiyac olduğunu bildirmək və vakansiyanın yaradılması üçün tələb göndərmək məqsədi daşıyır.

Eyni tip vakansiyalar üçün hər dəfə məlumatları sıfırdan daxil etməyə ehtiyac yoxdur. [**Vakansiya sifarişi şablonu**](job-order/vakansiya-sifarisi-sablonlarina-kecid.md) yaradaraq əvvəlcədən müəyyən edilmiş məlumatları yadda saxlaya bilərsiniz.

Şablon vasitəsilə:

* Standart vakansiya məlumatlarını əvvəlcədən təyin edə bilərsiniz;
* Eyni və ya oxşar vəzifələr üçün sifarişləri daha sürətli yarada bilərsiniz;
* Təkrarlanan məlumatların yenidən daxil edilməsinin qarşısını ala bilərsiniz;
* Şirkət daxilində vakansiya sifarişlərinin daha standart formada yaradılmasını təmin edə bilərsiniz.

Şablondan istifadə etdikdə əvvəlcədən müəyyən edilmiş məlumatlar sifarişə avtomatik əlavə olunur və ehtiyac olduqda onları dəyişdirə bilərsiniz.
