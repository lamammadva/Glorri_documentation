# Mərhələlərin idarə edilməsi

Hiring Stage bölməsi vakansiya üzrə işə qəbul mərhələlərinin yaradılması, idarə edilməsi və şablon (template) formasında istifadəsi üçün nəzərdə tutulub.

Bu bölməyə daxil olmaq üçün sol menyudan **Settings → Hiring Stage** yolunu izləyin.

Hiring Stage səhifəsi iki hissədən ibarətdir:

* **Recruiting**
* **Onboarding**

Sistemdə yeni şirkət yaradıldıqda hər iki bölmə üçün avtomatik olaraq standart (**Default**) template yaradılır. Bu template üzərində dəyişiklik edərək mərhələləri təşkilatın işə qəbul prosesinə uyğunlaşdıra bilərsiniz.

Bu bölmədə aşağıdakı əməliyyatları yerinə yetirmək mümkündür:

* mövcud template-i redaktə etmək;
* yeni mərhələlər əlavə etmək;
* mərhələlərin adını dəyişmək;
* mərhələləri silmək (Applied mərhələsi istisna olmaqla);
* mərhələlərin ardıcıllığını dəyişmək;
* yeni template yaratmaq;
* istənilən template-i **Default** olaraq təyin etmək.

Template daxilində hər bir mərhələni ayrıca redaktə etmək mümkündür.

Yeni mərhələ əlavə etmək üçün:

1. **Add Stage** düyməsini seçin.
2. Mərhələnin adını daxil edin.
3. İstəyə uyğun avtomatik əməliyyat (**Action**) seçin. Bu sahə məcburi deyil.
4. Mərhələnin kateqoriyasını seçin:
   * Applied
   * Shortlist
   * Interview
   * Offered
   * Hired
5. **Save** düyməsini seçərək dəyişiklikləri yadda saxlayın.

> **Qeyd:** **Applied** mərhələsi sistem mərhələsi olduğu üçün silinə bilməz.

Mərhələlərin yerini dəyişmək üçün onları sürükləyərək (**Drag & Drop**) istədiyiniz ardıcıllıqda yerləşdirə bilərsiniz.

### Yeni template yaratmaq

Yeni Hiring Stage template yaratmaq üçün **Create Template** əməliyyatından istifadə edin.

Yaradılan template siyahıya əlavə olunur və istənilən vaxt redaktə edilə bilər.

Əgər yeni template-i əsas şablon kimi istifadə etmək istəyirsinizsə, onun qarşısındakı **Make Default** seçimini aktiv edin.

> **Qeyd:** Default olaraq təyin edilən template yalnız bundan sonra yaradılacaq yeni vakansiyalara tətbiq olunur. Mövcud vakansiyalar əvvəlki template ilə işləməyə davam edir.

### Mövcud vakansiyaya template tətbiq etmək

Hiring Stage template-də edilən dəyişikliklər avtomatik olaraq mövcud vakansiyalara tətbiq olunmur.

Mövcud vakansiya üçün mərhələləri dəyişmək və ya yeniləmək üçün:

1. **Vacancies** bölməsinə daxil olun.
2. Müvafiq vakansiyanı açın.
3. **Edit** seçimini edin.
4. **Workflow → Hiring Goals & Team** bölməsinə keçin.
5. Buradan:
   * mərhələləri redaktə edə;
   * yeni mərhələ əlavə edə;
   * avtomatik əməliyyatlar (Actions) təyin edə bilərsiniz.

Yadda saxlanılan dəyişikliklər yalnız həmin vakansiyaya tətbiq olunur.
