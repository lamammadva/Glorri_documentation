# Rejection Message Templates

Diskvalifikasiya zamanı namizədə göndərilən rejection mesajları **Message Templates** bölməsindən idarə olunur.

**Sol panel → Settings → Templates  → Message Templates**

Burada sistem tərəfindən yaradılmış default rejection template-ləri görə bilərsiniz.

#### Rejection Template-i dəyişmək

1. **Message Templates** bölməsinə keçin.
2. Mövcud **Rejection** template-ini seçin.
3. Mesaj mətnini redaktə edin.
4. Lazım olduqda dinamik placeholder-lər əlavə edin.
5. **Save** düyməsinə klikləyin.

Yadda saxlanılan template daha sonra **Disqualification Reason** daxilində notification template kimi istifadə oluna bilər.

#### Yeni rejection template

İstəyə uyğun olaraq yeni rejection template yarada bilərsiniz.

Bu, müxtəlif diskvalifikasiya səbəbləri üçün fərqli mesajlardan istifadə etməyə imkan verir.
