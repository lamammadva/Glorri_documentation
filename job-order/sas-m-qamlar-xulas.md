# Əsas məqamlar (Xülasə)

**👤 İstifadəçinin strukturu**\
Şablon yaratmazdan əvvəl əməkdaşların düzgün Filial və Struktura təyin olunduğunu yoxlayın.\
→ Ətraflı: \[İstifadəçilərin və strukturların idarə edilməsi]

**🧩 Şablonun strukturu**\
Hər şablon müəyyən Filial + Struktur üçün yaradılır.\
→ Ətraflı:  \[[Yeni şablon yaradılması](yeni-sablon-yaradilmasi.md)]

**🤖 Avtomatik iş axını**\
İstifadəçi Vakansiya Sifarişi yaradarkən təsdiq prosesini özü seçmir, sistem avtomatik tətbiq edir.\
→ Ətraflı: \[[Vakansiya Sifarişinin yaradılması](vakansiya-sifarisinin-yaradilmasi.md)]

**✏️ Koordinatorun çevikliyi**\
Koordinator konkret sifariş üçün təsdiq prosesinə dəyişiklik edə bilər.\
→ Ətraflı: \[[Koordinator tərəfindən yoxlanılması](koordinator-t-r-find-n-yoxlanilmasi.md)]

**🔄 Ardıcıllıq və bildirişlər**\
Hər mərhələdən sonra sifariş növbəti şəxsə göndərilir, bildiriş yalnız ona gedir.\
→ Ətraflı: \[[Sifarişin təsdiqlənməsi və təsdiq zənciri](sifarisin-t-sdiql-nm-si-v-t-sdiq-z-nciri.md)]

**✅ Yekun status**\
Sonuncu təsdiqdən sonra sifariş "Draft" statusuna keçir.\
→ Ətraflı: \[[Yekun təsdiq](yekun-t-sdiq.md)]

**🔐 İcazələr və Superadmin səlahiyyəti**\
Adi istifadəçilər yalnız özlərinə aid sifarişlər üzərində əməliyyat apara bilər, Superadmin isə əvəzinə edə bilər.\
→ Ətraflı: \[[İstifadəçi rolları və icazələri](istifad-ci-rollari-v-icaz-l-ri.md)]
